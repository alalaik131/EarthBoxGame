# Тестирование
Выполнено в среде без Android SDK:
- Компиляция `Game.kt` + `Powers.kt` встроенным компилятором Kotlin 2.0.21 — успешно.
- Headless-симуляция (`tools/headless/SimTest.kt`): 5 пресетов мира, 12 000 тиков с войнами, огнём, метеором, торнадо, чёрной дырой, вулканом, бомбой, кислотой, потопом, ядерным взрывом, дождём/снегом, цикл сохранения/загрузки — без исключений.
- `tools/headless/Civ.kt`: рост одного королевства 3 → 63 жителей за 9000 тиков.
- Типы `GameView.kt`, `MainActivity.kt`, `Sprites.kt` проверены против временных заглушек Android API.
**Не выполнено:** реальная сборка Gradle, запуск на устройстве/эмуляторе, проверка FPS и жестов.
