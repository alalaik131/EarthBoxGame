# План проекта EarthBox
**Цель:** нативная Android-песочница по мотивам WorldBox с текстурами пользователя.
**Стек:** Kotlin, чистые Android View + SurfaceView (без сторонних библиотек), Gradle/AGP 8.5.2, minSdk 26, targetSdk 34.
**Допущения:** ландшафтная ориентация; русский интерфейс; офлайн, без аккаунтов; applicationId временный (`com.earthbox.game`).
**Критерии приёмки:** запуск → заставка → игра; рисование рельефа; спавн существ; рост поселений; войны; катастрофы; сохранение/загрузка.
## Этапы
1. Текстуры из атласа → спрайты — готово.
2. Ядро симуляции (`Game.kt`) — готово, проверено headless-тестом.
3. Рендер и жесты (`GameView.kt`) — написано, проверено на типы.
4. Интерфейс (`MainActivity.kt`) — написано, проверено на типы.
5. Сборка APK и тест на устройстве — ожидает окружения с Android SDK.
