# EarthBox

Песочница-бог в духе WorldBox: создавайте мир, населяйте его, наблюдайте за цивилизациями и устраивайте катастрофы.
Нативное Android-приложение (Kotlin, без внешних библиотек), графика — ваш Texture Pack.

## Возможности
- Генерация мира (5 пресетов: Континенты, Острова, Архипелаг, Пангея, Пустой мир), биомы по широте и высоте.
- Кисти рельефа: вода, песок, земля, трава, горы, снег, лава, камень, лес, ластик (размер кисти 1–10).
- 13 существ: люди, эльфы, дворфы, орки, свинья, корова, олень, лошадь, волк, слизь, паук, голем, дракон.
- Цивилизации: основание поселений, добыча дерева/еды, рост населения, здания 4 уровней, технологии, границы, войны и мир.
- Катастрофы: огонь, молния, метеор, бомба, ядерный взрыв, кислота, торнадо, чёрная дыра, землетрясение, вулкан, потоп.
- Природа: дождь, снегопад, «Жизнь», удобрение; огонь распространяется по лесам, лава остывает в камень.
- Осмотр существ и зданий, статистика, журнал событий, сохранение/загрузка.

## Управление
- Один палец — применить выбранную силу; инструмент «Рука» — двигать карту.
- Два пальца — перемещение и масштаб.
- Снизу: вкладки (Мир, Существа, Беды, Природа, Народы, Инструменты) и силы; «−/+» — размер кисти.

## Сборка
Нужны JDK 17 и Android SDK (платформа 34).

Windows (PowerShell): `.\gradlew.bat assembleDebug`
Linux/macOS: `./gradlew assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Без Android Studio: загрузите проект в GitHub-репозиторий — workflow `.github/workflows/build-apk.yml` соберёт APK и приложит его как артефакт.

Перед публикацией замените `applicationId` в `app/build.gradle.kts` и настройте подпись релиза через секреты CI (ключи в репозиторий не кладите).

## Структура
- `Game.kt` — вся логика мира (без Android-зависимостей).
- `GameView.kt` — рендер на SurfaceView и жесты.
- `MainActivity.kt` — интерфейс. `Powers.kt` — список сил. `Sprites.kt` — загрузка текстур.
- `app/src/main/assets/sprites` — вырезанные из атласа спрайты; `assets/ui/logo.png` — логотип.
- `tools/headless` — тесты симуляции без графики.
